A high-fidelity, cinematic news portal built with **CodeIgniter 4**, featuring a modern administrative dashboard, multi-channel notification system, and immersive visual storytelling.

- **Cinematic Editorial UI**: Modern, glassmorphic design optimized for high-readability.
- **Visual Stories**: Immersive, full-screen storytelling module.
- **Video News**: Dedicated video journalism section with interactive player.
- **Dynamic Polls**: Integrated user engagement widgets.

### 🛠️ Advanced Admin Dashboard
- **Bulk Content Management**: Streamlined workflows for news, videos, and visual stories.

## 🚀 Getting Started

### Prerequisites
- **PHP**: 8.2 or higher
- **Database**: MySQL 5.7+ / MariaDB 10.3+
- **WebServer**: Apache/Nginx (Pointed to the `/public` directory)

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/parvendrakumar/news.git
   ```
2. **Install Dependencies**:
   ```bash
   composer install
   ```
3. **Configuration**:
   - Rename `env` to `.env`.
   - Update `database.default.hostname`, `database.default.database`, etc.
   - Set your `app.baseURL`.
4. **Run Migrations/Seeds**:
   ```bash
   php spark migrate
   php spark db:seed MainSeeder
   ```
